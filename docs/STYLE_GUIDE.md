# DL Experiment Manager — UI 스타일 가이드

다크 테마 기준 디자인 토큰과 컴포넌트 규격입니다.
**값을 바꾸고 싶으면 `dl_exp_manager/theme/tokens.py` 한 곳만 고치면 됩니다.**
QSS는 이 토큰을 치환해서 생성되므로, 색을 하드코딩한 곳이 코드 어디에도 없어야 합니다.

---

## 1. 설계 원칙

이 앱은 **오래 켜 두고 표를 읽는 도구**입니다. 화려함보다 다음을 우선합니다.

1. **표가 주인공** — 색은 표에서 시선을 뺏지 않는 선에서만 쓴다. 강조색은 한 화면에 한두 군데.
2. **의미가 있을 때만 색** — 상태(running/failed), 최고 성능, 선택. 장식용 색은 쓰지 않는다.
3. **깊이는 그림자가 아니라 밝기로** — 다크 테마에서 그림자는 잘 안 보인다. 배경 단계(base → surface → elevated)로 계층을 만든다.
4. **숫자는 자릿수가 맞아야 한다** — 지표 비교가 핵심 작업이므로 표의 숫자는 tabular figures 또는 mono 폰트로 정렬한다.
5. **밀도 우선** — 한 화면에 최대한 많은 run이 보여야 한다. 여백은 넉넉함이 아니라 그룹 구분을 위해서만 쓴다.

## 2. 컬러 토큰

### 2.1 배경 / 표면

| 토큰 | 값 | 용도 |
|---|---|---|
| `bg.base` | `#16181D` | 창 전체 배경 |
| `bg.surface` | `#1C1F26` | 패널, 테이블 배경 |
| `bg.surface.alt` | `#20242C` | 테이블 교차 행(alternating row) |
| `bg.elevated` | `#232730` | 팝업, 드롭다운, 컨텍스트 메뉴, 카드 |
| `bg.input` | `#12141A` | 입력란 — 배경보다 **어둡게** 해서 "파인" 느낌 |
| `bg.hover` | `#2A2F3A` | 마우스 오버 |

> 규칙: 위로 뜨는 요소(팝업)는 **밝게**, 안으로 들어가는 요소(입력란)는 **어둡게**.

### 2.2 선 / 구분

| 토큰 | 값 | 용도 |
|---|---|---|
| `border.subtle` | `#2A2F3A` | 표 격자선, 패널 구분선 |
| `border.default` | `#333A47` | 입력란 테두리 |
| `border.strong` | `#3A4150` | 포커스 전 강조, 스플리터 핸들 |

표 격자선은 **세로선만** 그립니다. 가로선까지 그리면 밀도가 높을 때 시각적으로 시끄러워집니다.

### 2.3 텍스트

| 토큰 | 값 | 대비(on `bg.surface`) | 용도 |
|---|---|---|---|
| `text.primary` | `#E6E9EF` | 14.9:1 | 본문, 표 값 |
| `text.secondary` | `#9BA3B4` | 6.8:1 | 라벨, 캡션, 보조 정보 |
| `text.muted` | `#6B7488` | 3.6:1 | 플레이스홀더, 단위 |
| `text.disabled` | `#4E5666` | 2.3:1 | 비활성 (읽을 필요 없는 것에만) |

`text.muted` 이하는 **본문에 쓰지 마세요.** WCAG AA(4.5:1) 미만입니다.

### 2.4 강조색 (Accent)

| 토큰 | 값 | 용도 |
|---|---|---|
| `accent` | `#5B9DFF` | 기본 버튼, 링크, 포커스 링, 선택 |
| `accent.hover` | `#7FB4FF` | 호버 |
| `accent.pressed` | `#3F82E6` | 눌림 |
| `accent.bg` | `#1E2A3D` | 선택된 표 행 배경 |
| `accent.border` | `#2F4A78` | 선택 행 좌측 강조 바, 포커스 테두리 |

> 선택 행은 **강조색으로 배경을 채우지 말고** `accent.bg`(어두운 남색) + 좌측 2px `accent` 바로 표시합니다.
> 표 전체가 파랗게 뒤집히면 그 행의 지표 숫자를 읽기 어렵습니다.

### 2.4b 강조색 2 — CTA (`cta`)

| 토큰 | 값 | 용도 |
|---|---|---|
| `cta` | `#2DD4BF` | "새로 만들기" 류 주 액션 버튼 (`+ New Run`) |
| `cta.hover` | `#5EEAD4` | 호버 |
| `cta.pressed` | `#14B8A6` | 눌림 |
| `cta.text` | `#0E1116` | 버튼 위 텍스트 |

`accent`(파랑)는 선택 상태·활성 탭·포커스 전용으로 남겨 두고, "새로 만들기" 같은 주 액션
버튼은 `cta`(청록)로 구분합니다. 활성 탭이 파란색으로 강조된 화면에서 `+ New Run` 버튼까지
파란색이면 어느 쪽이 "지금 상태"고 어느 쪽이 "누를 수 있는 버튼"인지 헷갈립니다 —
색상 하나에 의미 두 개를 억지로 얹지 않습니다. `QPushButton[variant="cta"]` 로 적용합니다
(`variant="primary"` 는 accent, 폼 안의 Save 버튼처럼 별도 경쟁 상대가 없는 곳에 그대로 씁니다).

### 2.5 상태 색 (다크 전용으로 재조정)

라이트 테마용 구글 팔레트(`#1a73e8`, `#188038`, `#d93025`)는 다크 배경에서 탁합니다. 아래 값으로 대체합니다.

| 상태 | 토큰 | 값 | 아이콘 |
|---|---|---|---|
| queued | `status.queued` | `#8B93A7` (회색) | `○` |
| running | `status.running` | `#4DA3FF` (파랑) | `●` (은은한 펄스 애니메이션) |
| done | `status.done` | `#3FBF7F` (초록) | `●` |
| failed | `status.failed` | `#FF6B6B` (빨강) | `●` |

상태는 **점 + 텍스트**로 표시합니다(칩 배경 채움 ❌). 표 안에서 배경을 칠하면 행 선택과 충돌합니다.
Status 콤보(New Run 폼)와 상태 필터 드롭다운도 `widgets/common.py::colorize_status_items()` 로
같은 색을 입혀서, 목록을 펼쳤을 때도 상태를 글자부터 훑을 수 있게 합니다.

`server.busy`(`#3FBF7F`, done 과 같은 초록)는 서버 상태 바의 "GPU 사용 중" 표시 전용입니다.
`status.running`(파랑)과 값을 공유하지 않는 이유: "이 Run 이 running 상태"와 "이 서버가 지금
사용 중"은 서로 다른 질문이라, 같은 파랑을 쓰면 서버 바가 실제로는 "몇 대 중 몇 대가 바쁜지"를
보여줄 뿐인데 마치 Run 상태를 보여주는 것처럼 읽힙니다.

### 2.6 데이터 시각화 시리즈 색

시각화 패널과 GPU 슬롯이 공유하는 팔레트. 순서대로 순환합니다.

| # | 값 | | # | 값 |
|---|---|---|---|---|
| 1 | `#5B9DFF` | | 5 | `#4DD0E1` |
| 2 | `#3FBF7F` | | 6 | `#FF6B6B` |
| 3 | `#FFB454` | | 7 | `#A3BE8C` |
| 4 | `#C792EA` | | 8 | `#E5C07B` |

색맹 안전성을 위해 **색만으로 시리즈를 구분하지 않습니다.** 선 모양(실선/파선)이나 마커를 함께 씁니다.

### 2.7 의미 색 (지표 비교)

| 토큰 | 값 | 용도 |
|---|---|---|
| `metric.best` | `#3FBF7F` | 같은 Work 안 최고 성능 값 (`higher_is_better` 반영) |
| `metric.worst` | `#FF8A8A` | 최저 (옵션, 기본 꺼짐) |
| `metric.delta.up` | `#3FBF7F` | 비교 뷰에서 개선 |
| `metric.delta.down` | `#FF6B6B` | 비교 뷰에서 악화 |

## 3. 타이포그래피

### 3.1 폰트 스택

```python
UI_FONT_STACK = [
    "Pretendard",            # 1순위 — 한글+라틴 통일감, OFL 라이선스
    "Apple SD Gothic Neo",   # macOS 기본 한글 고딕
    "Malgun Gothic",         # Windows
    "Noto Sans KR",
    "Inter",                 # 라틴 대체
    "Segoe UI Variable",     # Windows 11
    "sans-serif",
]

MONO_FONT_STACK = [
    "JetBrains Mono",    # 1순위 — 경로/명령어 가독성, OFL
    "D2Coding",          # 한글 주석 섞인 config 에 강함
    "SF Mono",           # macOS
    "Cascadia Code",     # Windows
    "Consolas",
    "monospace",
]
```

**Pretendard를 1순위로 두는 이유:** 경로·모델명(라틴)과 UI 라벨(한글)이 한 줄에 섞이는 화면인데,
Inter 같은 라틴 전용 폰트를 쓰면 한글이 시스템 폰트로 폴백되면서 baseline과 굵기가 어긋납니다.
Pretendard는 두 문자셋을 한 벌로 커버하고, UI 용으로 다듬어진 높은 가독성으로 한국 앱/제품에서
널리 쓰입니다. 시스템에 설치돼 있지 않으면(기본 상태) macOS 는 Apple SD Gothic Neo, Windows 는
Malgun Gothic 처럼 각 OS 가 기본 탑재한 한글 고딕으로, 그마저 없으면 Noto Sans KR 로 폴백합니다.

**폰트 확보 방법 (택1):**
- 시스템 설치분만 사용하고 위 스택으로 폴백(기본값) — 저장소가 가벼움. Pretendard 가 없으면
  macOS/Windows 기본 탑재 고딕으로 자동 폴백되므로 추가 설치 없이도 크게 어색하지 않습니다.
- (권장) `assets/fonts/` 에 Pretendard + JetBrains Mono 를 동봉하고
  `QFontDatabase.addApplicationFont()` 로 로드 — 어느 PC에서 열어도 동일한 화면. 둘 다 OFL이라
  재배포 가능.

### 3.2 크기 체계 (pt)

| 역할 | 크기 | 굵기 | 비고 |
|---|---|---|---|
| Scope 타이틀 (`SR ▸ SSL2SL`) | 15 | 600 | 화면당 1개 |
| 섹션 헤더 (`— 경로 —`) | 11 | 600 | `text.secondary`, 자간 +2% |
| 표 헤더 | 11.5 | 600 | |
| 표 본문 / 본문 | 12 | 400 | |
| 폼 라벨 | 12 | 400 | `text.secondary`, 우측 정렬 |
| 경로 / 명령어 / config | 11 | 400 | **mono** |
| 캡션 / 상태바 | 11 | 400 | `text.secondary` |

크기 단계는 이 7개가 전부입니다. 새 크기를 추가하기 전에 기존 것으로 되는지 먼저 보세요.

### 3.3 숫자 정렬

지표 컬럼은 자릿수가 흔들리면 비교가 안 됩니다. 둘 중 하나를 반드시 적용합니다.

- Qt 6.7+ : `font.setFeature("tnum", 1)` — 비례 폰트에서 tabular figures 활성화
- 그 이하 : 지표 컬럼에 mono 폰트 적용

두 경우 모두 숫자 컬럼은 **우측 정렬**, 경로는 좌측 정렬입니다.

## 4. 스페이싱 & 형태

- **그리드: 4px.** 모든 여백은 4의 배수 (4 / 8 / 12 / 16 / 24).
- 패널 바깥 여백 `12`, 폼 행 간격 `6`, 섹션 사이 `16`, 버튼 내부 `6 12`.
- **모서리 반경**: 입력·버튼 `6px`, 팝업·카드 `8px`, 배지·GPU 슬롯 `4px`, 표 셀 `0`.
- **테두리 두께**: 항상 `1px`. 포커스만 `accent` 색 `1px` + 바깥 `2px` 글로우.
- **행 높이**: 표 기본 `26px`, 조밀 모드 `22px` (보기 메뉴에서 전환).

## 5. 컴포넌트 규격

### 5.1 테이블

```
┌────────────────────────────────────────────┐
│ Status │ Server │ Model    │ PSNR │ SSIM  │  ← 헤더: bg.elevated, 하단 1px border.strong
├────────────────────────────────────────────┤
│▏● done │ Srv 1  │ Restormer│ 32.41│ 0.8993│  ← 선택 행: accent.bg + 좌측 2px accent 바
│  ● done│ Srv 2  │ SwinIR   │ 32.72│ 0.9031│  ← 최고값은 metric.best 색 + 600 굵기
└────────────────────────────────────────────┘
```

- 세로 격자선만 `border.subtle`. 가로선 없음.
- 교차 행 `bg.surface.alt`.
- 정렬 표시는 헤더 우측 `▲/▼`를 `accent` 색으로.
- 경로 컬럼은 mono + 좌측 생략(`…/SSL2SL/restormer_x4`) — 뒤쪽이 구분에 중요하므로 **앞을 자릅니다.**

### 5.2 콤보박스 + 인라인 항목 관리

```
┌──────────────────────────┐
│ Restormer            ▾   │   ← 닫힘 상태
└──────────────────────────┘
      ↓ 펼침
┌──────────────────────────┐
│ Restormer              ✓ │
│ SwinIR                   │   ← 우클릭 → 이름 변경(F2) / 삭제
│ MambaIR                  │
├──────────────────────────┤   ← border.subtle 구분선
│ ＋ 새 항목 추가…          │   ← accent 색, 이 행은 "값"이 아님
└──────────────────────────┘
```

- `＋` 행은 항상 마지막, `accent` 색, 선택해도 값으로 채택되지 않습니다.
- 항목 우클릭 컨텍스트 메뉴: `이름 변경 (F2)` / `삭제 (Del)` / `이 Task 전용으로 만들기`.
- 삭제 시 그 값을 쓰는 기존 run이 있으면 **건수를 알려주고 기록은 보존**합니다(선택지에서만 제거).

### 5.3 버튼 위계

| 종류 | 배경 | 글자 | 사용처 |
|---|---|---|---|
| CTA | `cta` (청록) | `cta.text` | 화면당 1개, "새로 만들기" (`+ New Run`) |
| Primary | `accent` (파랑) | `#0E1116` | 폼 안의 Save 등 — 경쟁하는 CTA가 없을 때 |
| Secondary | `bg.elevated` + `border.default` | `text.primary` | 일반 동작 |
| Ghost | 투명 | `text.secondary` | 툴바, 아이콘 버튼 |
| Danger | 투명 + `#FF6B6B` 테두리 | `#FF6B6B` | 삭제 — 채우지 않음 |

### 5.4 GPU 슬롯 인디케이터

```
Server 1  H100 ×8   ██▊▊░░░░   3/8 busy
                    ↑  ↑  ↑
                 job1 job2 free
```

- 빈 슬롯: `border.subtle` 테두리만, 채움 없음.
- 사용 중: 시리즈 색으로 채움 — **같은 학습(run)에 속한 GPU는 같은 색**.
- 호버 시 툴팁으로 `모델 · Work · 경과시간 · 실행 명령어`.
- 서버가 offline이면 전체를 `text.disabled` 로 낮춥니다.

### 5.5 컨텍스트 메뉴

- 배경 `bg.elevated`, 테두리 `border.subtle`, 반경 `8px`, 항목 높이 `26px`.
- 파괴적 동작(삭제)은 **항상 맨 아래**, 구분선 위, `#FF6B6B`.
- 단축키는 우측에 `text.muted` 로 병기 — 사용자가 자연히 익히도록.
- 폴더 열기/수정/삭제 아이콘은 §5.6 참고. `editing.build_item_menu()` 를 쓰면 자동으로 붙는다.

### 5.6 아이콘

이모지(📁 ✎ 🗑)는 OS/폰트마다 굵기·정렬·색이 달라 다크 테마 안에서 붕 뜹니다. 반복적으로
쓰이는 폴더/수정/삭제/추가 네 개는 `theme/icons.py` 에서 `QPainter` 로 한 번 그려 `QIcon` 으로
씁니다(`icons.icon("folder" | "edit" | "delete" | "add", color)`) — 어디서든 같은 굵기·같은
정렬로 보이고, `theme.color("text.secondary")` 로 칠해 두면 테마를 바꿔도 같이 바뀝니다.
호버 시 아이콘 자체는 재색칠하지 않고(고정 비트맵이라 어렵다), 기존처럼 `QToolButton:hover`
의 배경색(`bg.hover`)으로만 반응을 줍니다. 새 아이콘이 필요하면 이 파일에 그리는 함수를
추가하세요 — 이모지로 되돌리지 않습니다.

그 외 툴바 아이콘(↻ 새로고침, ⤓ 내보내기, ⧉ 복사 등)은 유니코드 기호 그대로 둡니다 — 자주
바뀌지 않고, 이미 폴더/연필/휴지통만큼 흔히 마주치는 형태가 아니라 굳이 다시 그릴 우선순위가
낮습니다.

## 6. 상호작용 규약

앱 전체에서 **동일하게** 동작해야 합니다.

| 입력 | 동작 |
|---|---|
| `F2` | 선택 항목 이름 변경 (좌측 Task/Work / 콤보 항목 / 컬럼 헤더 / 지표 행) |
| `Del` | 선택 항목 삭제 (확인 다이얼로그) |
| `우클릭` | 그 항목에 대한 추가 / 이름 변경 / 삭제 |
| `더블클릭` | 경로 셀이면 폴더 열기, 그 외엔 편집 |
| `Ctrl+K` | 전역 검색 |
| `Enter` | 폼에서 저장 |
| `Esc` | 인라인 편집 취소 |
| 헤더 드래그 | 컬럼 순서 변경 / 폭 조정 - Task·Train/Inference 별로 자동 저장, 재실행해도 유지 |

Train/Inference 탭은 별도 줄을 쓰지 않고 탭 바 자체의 코너 위젯(우측)에 현재
Scope(`Task ▸ Work — 설명`)를 붙입니다(`QTabWidget.setCornerWidget`) — 세로 공간을 표 쪽에
더 내줄 수 있습니다.

## 7. 애니메이션

거의 쓰지 않습니다. 다음만 허용합니다.

- 호버/포커스 색 전환: `120ms ease-out`
- 팝업 페이드: `100ms`
- running 상태 점 펄스: `1.6s` 주기, 투명도 `0.45 ↔ 1.0`

표 정렬, 행 삽입/삭제에는 애니메이션을 넣지 않습니다. 데이터를 눈으로 좇는 데 방해됩니다.

## 8. 접근성 체크리스트

- [ ] 본문 텍스트 대비 4.5:1 이상 (`text.primary`, `text.secondary`만 사용)
- [ ] 상태를 색만으로 표현하지 않음 (아이콘 + 텍스트 병기)
- [ ] 포커스 링이 모든 대화형 위젯에서 보임
- [ ] 시각화 시리즈는 색 + 선 모양/마커로 이중 구분
- [ ] 폰트 크기 11pt 미만 사용 금지

## 9. 파일 구조 (구현 시)

```
dl_exp_manager/theme/
  tokens.py        ← 이 문서의 모든 값. 색을 바꾸려면 여기만 수정
  dark.qss.tpl     ← {{token}} 자리표시자를 쓰는 QSS 템플릿
  fonts.py         ← 폰트 스택 해석 및 번들 폰트 로드
  icons.py         ← 폴더/수정/삭제/추가 벡터 아이콘 (§5.6)
  __init__.py      ← apply_theme(app, name="dark")
assets/fonts/      ← (선택) Pretendard, JetBrains Mono
```

라이트 테마가 필요해지면 `tokens.py` 에 `LIGHT` 딕셔너리를 추가하기만 하면 됩니다.
QSS 템플릿과 위젯 코드는 손대지 않습니다.
